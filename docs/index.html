Opal Documentation

Official documentation for the Opal web browser.

About Opal

Opal is a lightweight web browser focused on delivering a clean, simple, and modern browsing experience.

The project is currently under active development and continues to evolve with new features, improvements, and bug fixes.

Technologies Used

Opal is built using the following technologies:

  • C — Low-level and performance-critical components.
  • C++ — Core browser functionality and features.
  • Swift — macOS integration and native functionality.
  • Visual Studio Code — Primary development environment.

Development Status

Opal is experimental software. Some features may still be incomplete, and users should expect occasional bugs while development continues.

Feedback and bug reports are valuable and help improve future releases.

Known Issues

History Window Cannot Be Closed

Opening the History window may cause it to become impossible to close using the normal interface controls.

Temporary workaround: Restart Opal if the History window becomes unresponsive.

Status: Under investigation.

Reporting Bugs

If you encounter an issue while using Opal, please include the following information when reporting it:

  • Steps to reproduce the problem.
  • Expected behaviour.
  • Actual behaviour.
  • Your Opal version number.
  • Screenshots or recordings, if available.
